# ThreeJS Interstellar Blaster

### Key Bindings

|   Key    |       Description        |
|----------|--------------------------|
|    W     |    Plane: move forward   |
|    S     |    Plane: move backward  |
|    D     |     Plane: move right    |
|    A     |     Plane: move left     |
|  Space   |       Shoot Missile      |


### Running

To play the game, run `python3 -m http.server` and head over to [http://127.0.0.1:8000/] in the  browser.
